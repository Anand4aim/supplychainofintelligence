# Articles

Published and in-progress long-form pieces that live on the site and are mirrored here for version control.

## Structure

| Folder | Contents |
|--------|----------|
| `canonical/` | The main paper and framework definitions |
| `teardowns/` | Company/technology teardowns decoded through the 10 layers |
| `opinion/` | Essays, predictions, and market observations |

## Submission format

Each article should be a Markdown file with frontmatter:

```yaml
---
title: "Title Here"
date: 2026-06-19
canonical_url: https://supplychainofai.com/live/{slug}
author: Anand Arivukkarasu
tags: [teardown, opinion, framework]
---
```

## Citation

All articles link back to `/paper` as the canonical reference. When citing externally, use:

> "Supply Chain of Intelligence™, the 10 layers of the generative AI stack."  
> https://supplychainofai.com/paper
